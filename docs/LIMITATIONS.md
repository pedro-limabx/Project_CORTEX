# Known limitations

- NEURON is not conscious and does not claim consciousness.
- There is no universal access to arbitrary applications.
- Cellular telephony depends on OS, carrier, permissions and/or controlled VoIP infrastructure.
- Banking depends on real APIs/Open Finance and authorization flows.
- Memory persistence is not yet production-ready.
- The planner is not yet a complete autonomous multi-step executor.
- Tool registry/executor exists, but model-driven structured tool calling is a later phase.
- API authentication is not yet production-ready.
